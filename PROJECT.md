# E-design compatibility project

## Status

The implementation plan is approved. The `shikimori.rip` compatibility map is in progress; CSS work starts after the planned fork setup.

## Goal

Update the E-design theme generator and its CSS coverage for the current Shikimori sites. Find and style unsupported page elements and states while retaining the visual language and behavior of every existing project style.

## Site order

1. Map and support `shikimori.rip`.
2. After the `.rip` completion checkpoint, map and support `shikimori.io`.

## Operating context

- Work is performed under the five-hour usage windows of a ChatGPT $20 subscription and may pause when a window is exhausted.
- The planning pass must choose a token-efficient workflow, assign Luna, Terra, and Sol only where justified, and select the Sol reasoning level used by the orchestrator.
- Work must be resumable through concise checkpoints without new project tests, unnecessary documentation, speculative tasks, or redundant verification.

## Delivery direction

The updated generator is intended to become a forked continuation under the user's GitHub account and to be published as its own GitHub Pages site. Until the user authorizes remote work, development remains local and the existing upstream remote remains unchanged.
